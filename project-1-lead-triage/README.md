# Project 1: Multi-Agent Support & Lead Triage Engine

## Overview
An automated pipeline that receives inbound messages, parses customer data, scores intent using an LLM, and routes leads to the appropriate system.

## Stack
* **Make.com:** Workflow orchestration, webhooks, and routing.
* **Postman:** API endpoint validation and payload testing.
* **LLM API:** Intent classification and structured JSON extraction.
