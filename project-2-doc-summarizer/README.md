# Project 2: Automated Knowledge Extraction & Multi-Format Summarizer

## Overview
An automated pipeline that ingests long-form raw text, executes multi-attribute extraction via LLM, and publishes formatted summaries while gracefully handling API rate limits.

## Stack
* **Make.com:** Data orchestration, string parsing, and error-handling directives.
* **LLM API (Gemini):** Multi-pass prompt extraction.
* **Postman:** Endpoint testing and payload simulation.
