# Project 3: Automated REST API Verification & Contract Testing Suite

## Overview
A comprehensive Postman automated testing suite that validates endpoint status codes, response latencies, schema integrity, and dynamic cross-request token passing.

## Stack
* **Postman:** Request authoring, collection runners, pre-request scripts, automated test assertions (JavaScript/Chai).
* **REST APIs:** Multi-stage CRUD operations and dynamic payload handling.
